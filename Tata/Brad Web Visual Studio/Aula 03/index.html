Aula 3 - Formatação com CSS

Utilizando tags(tag)

Utilizando classes (class="nomeclasse")

No HTML, inserimos o atributo nomeado com a palavra class, acrescido do simbolo =, e o nome da classe envolvido por aspas duplas.

No arquivo Css, criar a classe utilizando o ponto, o nome da classe e abertura de chaves para iniciar a formatação

Utilizando indentificadores (id="ident")

No HTML, inserimos o atributo nomeado com a palavra id, acrescido do simbolo =, e o nome do indentificador envolvido por aspas duplas.

No arquivo CSS, criar o indentificador utilizando o simbolo#, o nome do indentificadore a abertura de chaves para iniciar a formatação.
